# Meu primeiro projeto com o Git
📌 Sobre o Projeto

Esta calculadora foi desenvolvida com foco em:

Praticar JavaScript manipulando eventos e lógica matemática

Criar um layout limpo e intuitivo usando CSS moderno

Estruturar a página com HTML semântico

Usar Git e GitHub como um dev profissional

Criar um projeto próprio para portfólio

Ela permite operações básicas:
✔ Adição
✔ Subtração
✔ Multiplicação
✔ Divisão
✔ Porcentagem
✔ Inversão de sinal
✔ Limpar tudo (AC)

Tudo funcionando com atualização instantânea no visor, estilo calculadora do iPhone.

🚀 Tecnologias Utilizadas
Tecnologia	Descrição
HTML5	Estrutura da interface
CSS3	Estilização moderna com sombras e responsividade
JavaScript	Lógica da calculadora e controle das funções
Git	Controle de versão
GitHub	Publicação do projeto
🖼 Preview do Projeto

Você pode abrir o arquivo index.html no navegador pra usar a calculadora:

📂 calculadora-git/index.html

🧩 Como Funciona

A lógica da calculadora funciona usando:

Eventos de clique nos botões

Manipulação do DOM

Uso de variáveis internas para armazenar valores

Execução dinâmica das operações no JavaScript

👨🏻‍💻 E tudo foi digitado manualmente, linha por linha, para desenvolver raciocínio lógico e prática real.
